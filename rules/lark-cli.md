# Lark CLI

Use `lark-cli` for Feishu/Lark operations. Read its installed guides before API calls:

- `lark-cli skills read lark-shared` for identity, authentication, and safety.
- `lark-cli --help` to select a domain, then `lark-cli skills read lark-<domain>` for its guide.

Use the installed CLI's help and schema for command details. Do not keep a local copy of its documentation.
