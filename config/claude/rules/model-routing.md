# Model roles outside BB

When `BB_THREAD_ID` is set, follow the BB Custom Instructions delegation policy.
Use BB child threads for delegation. The native role definitions below apply
only when running outside BB.

Use the main Opus session to own the approach and review the final result.
For bounded codebase lookups, use Explore. For official documentation, use researcher.
For implementation with an agreed approach, use worker and assign explicit file ownership.
Delegate when the separate task helps the current work. Handle routine changes directly.
Keep each delegation brief and focused. Do not pass the full transcript to a subagent.
Keep subagent effort and model fields in effect; do not override them per invocation.

When the advisor tool is available, consult it before a substantial plan, after the
same error occurs twice, and before declaring a long task complete. Give it the
decision and the uncertainty to review. Skip advisor calls for routine edits.
If the advisor is unavailable, report the missing review and check the work directly.
