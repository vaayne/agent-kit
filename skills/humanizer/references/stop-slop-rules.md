# Stop-slop rules

Use this as the final hard cleanup pass. It is stricter than the broad AI-pattern catalog.

## Core rules

1. **Cut filler phrases**
   - Remove throat-clearing, emphasis crutches, adverbs, softeners, hedges, and meta commentary.
   - Bad: Here's the thing, It turns out, Let me be clear, At its core, In today's..., This matters because, Make no mistake.

2. **Break formulaic structures**
   - Avoid binary contrasts, negative lists, dramatic fragments, rhetorical setups, false agency.
   - Bad: Not X, but Y. The answer isn't X, it's Y. What if I told you...? X. That's it.

3. **Use active voice**
   - Every sentence should have a real subject doing the action when possible.
   - Bad: The decision emerged. Mistakes were made. It is believed that.

4. **Name the actor**
   - Abstractions do not act.
   - Bad: Data tells us. Markets reward. The culture shifts. The complaint becomes a fix.
   - Better: The analyst read the data. Buyers paid more. The team changed behavior. The team fixed it.

5. **Be specific**
   - Replace vague declaratives with the actual implication.
   - Bad: The stakes are high. The implications are significant. The reasons are structural.

6. **Put the reader in the room**
   - Avoid distant narrator voice.
   - Bad: People tend to... Nobody designed this. This happens because...
   - Better: You ship the workaround. Your team stops asking who owns it.

7. **Vary rhythm**
   - Mix sentence lengths. Avoid three-item slogan cadence. Do not end every paragraph with a punchline.
   - Final rewrite must contain no em dash or en dash.

8. **Trust readers**
   - No apologizing, hand-holding, permission-granting, or quotable one-liners.
   - If it sounds like a pull quote, rewrite it.

## Phrase replacements

| Avoid               | Use                    |
| ------------------- | ---------------------- |
| navigate challenges | handle, address        |
| unpack              | explain, examine       |
| lean into           | accept, embrace        |
| landscape           | situation, field       |
| game-changer        | important, significant |
| double down         | commit, increase       |
| deep dive           | analysis, examination  |
| take a step back    | reconsider             |
| moving forward      | next, from now         |
| circle back         | return to, revisit     |
| on the same page    | aligned, agreed        |

## Quick checks

Before delivering:

- Any adverbs or empty intensifiers? Cut them.
- Any passive voice hiding an actor? Rewrite.
- Any inanimate thing doing a human verb? Name the person or system.
- Sentence starts with What/When/Where/Which/Who/Why/How? Restructure unless it is a real question.
- Any "here's what/why/this/that" construction? Cut to the point.
- Any "not X, it's Y" contrast? State Y directly.
- Three consecutive sentences have the same length? Break the rhythm.
- Paragraph ends with a slogan? Vary it.
- Any `—` or `–`? Replace it.
- Any vague declarative? Name the specific effect.
- Any meta-joiner like "The rest of this essay"? Delete it.

## Scoring

Rate 1-10:

| Dimension    | Question                      |
| ------------ | ----------------------------- |
| Directness   | Statements or announcements?  |
| Rhythm       | Varied or metronomic?         |
| Trust        | Respects reader intelligence? |
| Authenticity | Sounds human?                 |
| Density      | Anything cuttable?            |

Below 35/50: revise.
